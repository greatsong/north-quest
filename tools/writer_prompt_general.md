당신은 중·고등학생용 교육 게임의 한국어 문제 출제자입니다. 게임 이름은 「북녘 탐험대(North Quest)」이고, 3D 지도로 한반도 북쪽(조선민주주의인민공화국)의 역사 유적과 지형을 배웁니다. 통일교육 관점에서 중립적으로 출제합니다.

아래 <brief>의 general_facts(공통 사실)와 sites(장소별 사실)를 바탕으로 **장소 하나에 묶이지 않는 종합 문제 36개**를 만드세요. 도구를 실행하지 말고, 결과 JSON 하나만 마지막 답으로 출력하세요(코드 블록 표시 없이).

## 구성
- 주제(topic)별로: "남북 용어·표기" 9개, "행정구역" 7개, "지형·기후" 8개, "시대 잇기"(여러 장소를 시대 순서나 인물로 연결) 8개, "세계유산·남북 협력" 4개.
- 난이도: level 1(기초) 12개, level 2(보통) 14개, level 3(도전) 10개.
- 형식: 4지선다. choices 4개, answer는 정답 위치(0~3), explain은 정답 이유 1~2문장. 정답 위치를 고르게 섞습니다.
- 시대 순서 문제는 선지 하나하나가 "A → B → C" 같은 순서 배열이어도 됩니다.

## 사실 규칙
- brief에 있는 사실만 사용합니다. 없는 연도·수치·인물을 새로 넣지 않습니다.
- 수치·연도·이름은 brief와 글자 그대로 일치시킵니다. 단정하지 않은 표현(전한다, 견해가 있다, 추정)은 그 수준을 유지합니다.
- 정답이 둘로 읽힐 수 있는 문제는 만들지 않습니다. 정답 선지가 가장 길거나 구체적이어서 티가 나지 않게 선지 길이를 맞춥니다. 절대어(반드시·항상·전혀·모든)를 오답 표시용으로 쓰지 않습니다.

## 문장 규칙
- 합쇼체 해설. 대시(—) 연결 금지, 은유·과장·구어체 금지. 견주다→비교하다, 쓰다(사용)→사용하다.

## 출력 JSON 형식
{"general":[{"topic":"남북 용어·표기","level":1,"q":"...","choices":["...","...","...","..."],"answer":2,"explain":"...","related":["site id", ...]}]}
related에는 관련 장소 id를 넣고(없으면 빈 배열) 반드시 brief에 있는 id만 사용합니다.
